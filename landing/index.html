A conta da viagem em grupo, resolvida.

Cada gasto na moeda local, convertido pela cotação do dia do pagamento, com o acerto final entre os viajantes.

Um gasto, três cálculos

  1. Entrada 200 EUR Aluguel do carro, pago por James, dividido entre James e Bond.
  2. Conversão EUR para BRL Cotação da data do pagamento, não a de hoje. A taxa fica salva no gasto.
  3. Divisão Bond deve a James O valor em reais é repartido entre os participantes e entra no saldo líquido da dupla.

Celular na viagem, desktop na mesa

O app tem layout mobile e desktop, tema claro e escuro, e um modo para ocultar os valores. Os prints usam a viagem de demonstração (James e Bond), com dados fictícios.

Decisões que valem a conversa

O que está no código, sem enfeite. Cada item tem um motivo e um limite.

Cotação do dia do pagamento

A conversão usa a cotação da data em que o gasto foi pago, via AwesomeAPI. Em fim de semana ou feriado, o servidor recua até 7 dias até achar uma cotação. O navegador nunca chama a API de câmbio direto: passa por /api/exchange-rate. Se a consulta falhar, USD, EUR e GBP usam uma taxa fixa aproximada; para as outras moedas o app não inventa valor.

for (let backDays = 0; backDays <= 7; backDays += 1) {
  candidateDate.setDate(baseDate.getDate() - backDays);
  const pair = `${upperCurrency}-BRL`;
  // consulta o dia; se não houver cotação, tenta o anterior
}

Dívidas compensadas por dupla

Se Bond deve R$ 145 a James num gasto e James deve R$ 116 a Bond em outro, a aba Devendo mostra só a diferença. Cada pendência pode ser marcada como paga.

Bond → James R$ 4.110,03

Dados no seu disco

O estado da viagem é um JSON local, sem banco. A gravação é atômica (arquivo temporário e rename), guarda a versão anterior, valida o formato e aceita até 5 MB. Se o arquivo estiver corrompido, o app avisa e não salva por cima.

API só para localhost

O middleware do Vite recusa pedidos com Host ou Origin fora de localhost, exige Content-Type: application/json e bloqueia o download direto do arquivo de dados.

IA opcional, nunca obrigatória

Escreva "Aluguel do carro 200 EUR dividido" e o Gemini devolve descrição, valor, moeda e categoria em JSON. Sem chave, o resto funciona igual. Como o Vite embute a chave no JavaScript, o uso é local.

Stack e limites

Stack

  • React 19
  • TypeScript
  • Vite 6
  • @google/genai
  • AwesomeAPI
  • Tailwind via CDN

O que ele não é

  • Não é um app hospedado: roda na sua máquina, com um usuário só.
  • Não tem login nem banco. A migração para o Supabase está proposta em SUPABASE_SETUP.md, mas não foi implementada.
  • A divisão é sempre igual entre os participantes de cada gasto.

Como rodar

Precisa de Node.js 20 ou superior. Num clone novo, o app abre com a viagem de demonstração.

git clone https://github.com/Miguel-de-Castro/SmartTrip.git
cd SmartTrip
npm install
npm run dev

Abra http://localhost:3000. Ao salvar o primeiro gasto, o arquivo data/tripState.local.json é criado e passa a guardar os seus dados (ele fica fora do git). Para ligar a entrada inteligente, copie .env.example para .env.local e coloque a sua GEMINI_API_KEY.
